# 蓝晒漏光补晒准入台

由古法蓝晒底片整理室扩出的漏光补晒准入台，业务按文件拆分：

- `judge.js`：判定（准入规则、曝光位分配、修边换人复核、更正重算，纯逻辑）
- `archive.js`：存档（JSON 库、登记/更正/补晒完成/修边/复核、旧版留档，列表/队列/统计同源派生）
- `page.js`：页面（HTML 与前端交互）
- `server.js`：仅 HTTP 路由

运行：

```bash
npm start
```

访问 `http://localhost:3040`。数据保存在 `data/light-leak-resun-station.json`。

## 规则

- 同片仅一张未结束检测单：重复登记沿用首次，不重复占曝光位。
- 登记漏光占比、遮挡批次、补晒秒数和检查人。
- 占比超 15%、遮挡批次停用（未知批次按停用）或补晒不足 90 秒：只转待修边，不占曝光位。
- 全部达标才准入，按 1–6 号顺序占曝光位。
- 补晒完成让出曝光位转修边；修边须换人复核两次，两次漏光均不高于 5% 才入盒，任一轮超 5% 本轮作废重修。
- 更正漏光占比或遮挡批次会让结论失效、复核痕迹清空并按现值重算，旧版整单留档。
- 列表、曝光队列、顶部统计均从同一份检测单派生，刷新后一致。
